# AGENTS.md

## 项目目标

这是一个非官方的 Claude Code 中文自学网站，基于 Claude Code 官方文档，引导用户通过真实练习逐步掌握安装、协作、验证、扩展、自动化和安全边界。

## 技术与预览

- 网站由原生 HTML、CSS 和 JavaScript 构成，无依赖安装或构建步骤。
- 本地预览入口是 `index.html`；也可用 `python3 -m http.server 8000` 启动 HTTP 预览。
- 不引入前端框架或包管理器，不新增测试脚手架。

## 页面约定

- 沿用现有暖米白、陶土橙、炭黑的编辑式视觉与课程页组件。
- 保持响应式布局、键盘焦点、跳转正文链接和 reduced-motion 支持。
- 首页和课程页共用 `styles.css`、`course.css` 与 `script.js`；复制按钮使用 `#copy-prompt` 或 `data-copy-target`。
- 修改页面内导航时，确认目标文件与锚点存在且可正常跳转。
- 每页保留一个主标题、语义化目录、实战练习、官方来源卡和核对日期。

## 内容约定

- 内容以 `https://code.claude.com/docs/llms.txt` 中的官方文档为依据，不把 Codex 或其他工具的术语和行为套用到 Claude Code。
- 全站使用简体中文，保留产品术语、命令、路径和 API 名称原文。
- 区分官方事实与实战建议；套餐、平台、模型和预览功能注明限制。
- 不展示真实凭据，不将高风险权限模式或绕过检查作为推荐做法。
- 产品文档变化后更新相关课程、来源日期和本文件中不再准确的说明。
