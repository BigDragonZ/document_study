01 · Choose your surface

同一个 Claude Code，可以从不同入口使用。

Claude Code 能读取代码库、编辑文件、运行命令并连接开发工具。终端 CLI 适合完整学习工作方式；IDE、Desktop 和 Web 则把同一套 agent 能力带进不同工作环境。

Terminal / CLI

在项目目录直接工作，适合学习命令、权限、会话、脚本与自动化。

VS Code / JetBrains

把对话、代码和 diff 放在编辑器旁，减少窗口切换。

Desktop / Web

Desktop 连接本地项目；Web 在云端环境处理仓库任务。两者执行位置不同。

手册建议

第一次学习先用 CLI 跑通核心流程，再按场景选择其他入口。多数入口需要 Claude 订阅或 Anthropic Console 账号；第三方提供商和具体功能可用性见官方说明。

02 · Install

按你的系统选择安装命令。

官方推荐原生安装。下面的命令来自当前 Quickstart；请先在官方页面核对，再在对应终端中运行。安装器下载期间可能没有进度显示。

macOS / Linux / WSL · 原生安装
curl -fsSL https://claude.ai/install.sh | bash
Windows PowerShell
irm https://claude.ai/install.ps1 | iex
Windows CMD · 不要在 PowerShell 中混用
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

macOS 也可使用 brew install --cask claude-code，Windows 可使用 winget install Anthropic.ClaudeCode。Homebrew 与 WinGet 安装需要分别用包管理器升级；原生安装会自动后台更新。

安装后打开新终端验证
claude --version

若提示找不到 claude，先检查 PATH；若出现 && 语法错误，可能把 CMD 命令粘贴到了 PowerShell。403、HTML 语法错误或其他安装问题请对照官方排障页，不要盲目重复执行。

03 · Start a session

在你想让它理解的项目目录启动。

  1. 1
    进入项目

    用 cd /path/to/your/project 换成实际项目路径。工作目录决定 Claude 首先看到的项目上下文。

  2. 2
    运行 claude

    首次使用会引导登录。可使用 Claude Pro、Max、Team、Enterprise，或 Console/API 及受支持的云服务账号。

  3. 3
    先问只读问题

    例如“这个项目做什么”“使用了哪些技术”“主入口在哪里”。Claude 会按需读取文件，不必手动粘贴整个项目。

  4. 4
    查看可用命令

    输入 /help；以后用 /resume 继续历史会话，用 /login 切换或重新认证账号。

启动与第一条只读任务
cd /path/to/your/project
claude
FIRST PROMPT

请先探索这个项目，告诉我它的用途、技术栈、启动与测试命令，以及关键入口。请引用文件路径；先不要修改文件。

04 · Make a small change

第一次修改要小，完成条件要清楚。

官方 Quickstart 建议从添加一个简单函数开始。实际项目中，可以选一个易验证的小修复：描述症状和约束，观察 Claude 展示的操作，在需要时批准，再检查 diff 与测试结果。

明确行为

不要只说“修一下”，而要说清输入、异常和期望结果。

审查权限

文件编辑和命令是否询问取决于当前权限模式。CLI 可用 Shift+Tab 切换。

验证结果

要求运行项目已有检查，并报告命令与结果；你也应查看实际改动。

SMALL TASK

在现有 calculator 模块中添加一个 divide 函数，保持当前代码风格和导出方式。覆盖正常除法与除数为零的情况，添加并运行对应测试。不要修改无关文件，不要提交。

这只是练习模板。请按项目已有接口、测试框架和错误处理约定调整，不要让示例覆盖真实项目设计。

05 · Essential commands

先掌握这五条启动方式。

命令用途
claude在当前项目启动交互会话。
claude "task"启动交互会话并带入初始任务。
claude -p "query"执行一次非交互查询后退出。
claude -c继续当前目录最近一次会话。
claude -r打开历史会话选择器。
/clear

清空当前上下文，开始一个干净任务；历史会话仍可恢复。

/exit 或 Ctrl+D 两次

退出当前 Claude Code 会话。

06 · 实战练习

用 20 分钟完成第一次可靠协作。

  1. 运行 claude --version，记录版本输出；如果未安装，先按上文官方方式安装。
  2. 在一个允许实验的小项目中启动 claude，发送首页的只读探索任务。
  3. 核对它给出的启动命令和入口是否真有文件依据，继续追问一个你不理解的模块。
  4. 完成一个不影响核心逻辑的小改动，要求添加或更新验证并实际运行。
  5. 查看 diff，记录修改文件、验证命令和仍不确定的地方。
完成标准你能说清 Claude 在什么目录工作、读了哪些证据、改了什么、运行了什么检查；没有仅凭一句“已完成”就结束。
