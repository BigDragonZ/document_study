01 · Shell

启动、继续、分支与更新。

命令用途
claude在当前目录启动交互会话
claude "explain this project"带初始提示启动交互会话
claude -p "query"执行一次非交互任务并退出
claude -c继续当前目录最近会话
claude -r打开会话选择器
claude -r "auth-refactor"按名称或 ID 恢复会话
claude -c --fork-session从最近会话分出新会话 ID
claude --from-pr 123恢复与指定 PR 关联的会话
claude -w feature-auth在隔离 worktree 中启动
claude --version查看安装版本
claude update更新到最新版本
claude auth status查看认证状态

02 · In-session commands

命令只在消息开头被识别。

命令用途
/help 或 /查看帮助或当前可用命令与 Skills
/init生成项目 CLAUDE.md 初稿
/memory查看或编辑项目记忆
/plan进入 Plan Mode
/model / /effort调整模型与推理投入
/permissions查看或更新权限
/config / /status打开设置或状态页
/mcp管理 MCP 与认证
/agents / /tasks管理 subagents 或查看后台任务
/rename <name>给当前会话命名
/resume / /branch切换会话或创建会话分支
/diff查看当前改动
/code-review审查当前分支改动
/export [filename]导出当前对话
/usage查看订阅使用限制与速率状态
/exit退出会话

03 · Keyboard

快捷键受终端和平台影响。

按键用途
Shift+Tab循环权限模式；当前模式看状态栏
Esc中断当前动作，保留上下文以便纠正
Esc + Esc打开 rewind / summarize 菜单
Ctrl+C取消当前输入或生成
Ctrl+D发送 EOF 退出；部分流程需要两次
Ctrl+G在默认编辑器中编辑提示或计划
Ctrl+L清屏但保留对话历史
Ctrl+R反向搜索命令历史
Ctrl+B将运行中的命令或 agent 转入后台；tmux 中按两次
\ + Enter跨终端通用的多行输入方式
! 开头Bash mode，命令与输出进入会话
@引用文件路径并自动补全

按 ? 查看你当前环境可用的快捷键。macOS 的 Option/Meta 与 Shift+Enter 可能需要终端配置；不要跨平台机械套用。

04 · Context + recovery

先判断你要清理、压缩、恢复，还是分支。

操作适用情况注意
/context查看上下文占用只是观察，不会清理
/compact [重点]保留同一任务但压缩历史给出要保留的重点
/clear切换到无关任务清空上下文，历史仍可恢复
/rewind恢复代码、对话或两者不覆盖 Bash 与外部副作用
/branch从当前点尝试另一方向原会话保留，新会话有新 ID
/btw <question>不污染主对话的快速旁问答案不进入主会话历史

05 · Automation flags

自动化时，输出和权限都要显式。

参数用途
--output-format text|json|stream-json选择非交互输出格式
--json-schema '<schema>'要求符合 JSON Schema 的结构化结果
--max-turns 3限制 agentic turns，达到上限会报错
--max-budget-usd 5.00API 调用的预算停止条件
--allowedTools "Read,Grep"精确预批准工具，不是限制可用工具的总开关
--tools "Read,Grep,Glob"限制本次可用内置工具
--permission-mode plan指定启动权限模式
--no-session-persistence非交互任务不保存会话，之后不可恢复
--append-system-prompt "..."在默认系统提示后补充指令
只读 JSON 查询
claude -p "List the project's test commands" --tools "Read,Grep,Glob" --output-format json

06 · Troubleshooting

先定位层级，再针对症状查官方错误。

  1. 1
    安装与登录

    检查 claude --version、PATH、claude auth status、网络和账号类型。

  2. 2
    设置没有生效

    用 /status 看来源，用 claude doctor 查无效配置，再查优先级与键作用域。

  3. 3
    扩展没有出现

    MCP 用 claude mcp list 或 /mcp；Skills、Hooks、CLAUDE.md 检查实际加载和配置。

  4. 4
    会话运行异常

    用 /doctor 做设置体检，用 /debug <症状> 查看当前会话调试日志。

  5. 5
    按错误原文查

    记录完整错误、版本、平台和最小复现，在 Error reference 中匹配，不反复盲试。

07 · Glossary

六个容易混淆的词。

Agentic loop

模型借助工具反复收集上下文、行动并验证的循环。

Context window

当前请求可携带的有限工作信息，包括对话、文件与工具结果。

Compaction

把较早会话历史压缩成摘要，释放上下文空间。

Subagent

在独立上下文中完成子任务并返回摘要的 agent。

MCP

把外部工具和数据以标准协议连接到 Claude 的方式。

Checkpoint

会话级恢复点，不是长期版本历史或外部操作撤销。

08 · 实战练习

建立自己的高频命令卡。

  1. 在一次真实会话中输入 /，查看当前版本实际提供的命令。
  2. 分别使用 /context、/rename 和 /resume，观察状态变化。
  3. 用 claude -p 做一次只读 JSON 查询，并解析结果。
  4. 故意查看一个不存在的会话或错误配置，练习读取完整错误并定位来源。
  5. 从本页选出你真正常用的十条，其他命令保留官方链接按需查询。
完成标准你的命令卡来自当前版本真实界面与输出；能快速找到上下文、权限、恢复和排障入口。
