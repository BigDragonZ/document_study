学习入口

  • Godot Docs – 4.7 branch：文档首页、版本和离线文档入口。

  • Your first 2D game：Dodge the Creeps 完整 2D 游戏教程及素材入口。
  • Your first 3D game：Squash the Creeps 进阶 3D 教程及素材入口。

基础概念

  • Nodes and Scenes：节点特征、场景树、主场景、运行场景和 res://。
  • Creating instances：PackedScene、实例化、属性覆盖、Resource 共享与 Make Unique。
  • Creating your first script：extends、成员变量、_init()、_process(delta)、Vector2 和帧率无关运动。
  • Listening to player input：Input 单例、输入动作、持续输入和方向控制。
  • Using signals：编辑器/代码连接信号、Timer、自定义信号、参数与 emit()。

完整 2D 项目

  • Coding the player：玩家输入、归一化、动画、边界限制、受击信号和延迟禁用碰撞。
  • Creating the enemy：Mob 场景、RigidBody2D、随机动画和离屏清理。
  • The main game scene：Main、Timer、Path2D/PathFollow2D、PackedScene 和生成流程。
  • Heads up display：CanvasLayer、HUD、开始/结束流程和用组清理旧敌人。

语言参考

  • GDScript reference：语言特性、关键字、类型、运算符、控制流、类、导出属性和信号。

  • Animation：动画手册入口。
  • User interface (UI)：Control、布局、主题和界面手册入口。

使用建议

先通过教程理解概念，再用类参考查询精确 API。阅读类参考时确认页面仍位于 en/stable，避免把其他 Godot 版本的示例直接混入本项目。
