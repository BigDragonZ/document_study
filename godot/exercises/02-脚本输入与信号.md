# 练习 02：脚本、输入与信号

## 前置知识与准备

- 已完成[练习 01](01-基础场景与实例化.md)。
- 已读：[GDScript 与游戏循环](../notes/03-GDScript与游戏循环.md)、[输入与信号](../notes/04-输入与信号.md)。
- 新建 Godot 4.7 项目，保留默认 `icon.svg`。

## 目标

制作一个可转向、前进、暂停和闪烁的图标。按钮切换运动时，同时发出带参数的自定义信号，由另一个脚本更新状态文字。

最终场景结构：

```text
Main（Node2D，main.gd）
├── Sprite2D（sprite_2d.tscn 实例，sprite_2d.gd）
│   └── Timer（Autostart 开启）
├── Button（Text = Toggle motion）
└── StatusLabel（Label）
```

## 第一部分：让图标自动运动

1. 创建 `Sprite2D` 场景，设置 Texture 为 `icon.svg`。
2. 附加 `sprite_2d.gd`，使用空模板。
3. 写入：

```gdscript
extends Sprite2D

signal motion_toggled(is_running: bool)

@export var speed := 400.0
@export var angular_speed := PI

func _process(delta: float) -> void:
	rotation += angular_speed * delta
	var velocity := Vector2.UP.rotated(rotation) * speed
	position += velocity * delta
```

4. 保存为 `sprite_2d.tscn` 并运行当前场景。

### 阶段验收

- 图标旋转并沿当前朝向运动。
- 在 Inspector 修改 `speed` 后，运行速度发生相应变化。
- 你能解释代码中两个 `delta` 分别控制什么。

## 第二部分：改为玩家输入

把 `_process()` 替换为：

```gdscript
func _process(delta: float) -> void:
	var direction := 0.0
	if Input.is_action_pressed("ui_left"):
		direction = -1.0
	if Input.is_action_pressed("ui_right"):
		direction = 1.0
	rotation += angular_speed * direction * delta

	var velocity := Vector2.ZERO
	if Input.is_action_pressed("ui_up"):
		velocity = Vector2.UP.rotated(rotation) * speed
	position += velocity * delta
```

### 阶段验收

- 未按键时图标不自动旋转或移动。
- 左/右键控制转向，上键沿当前朝向前进。
- 同时松开按键后，图标停止改变位置和旋转。

## 第三部分：按钮、Timer 和自定义信号

1. 在 Sprite2D 场景内添加子节点 `Timer`，保持默认 Wait Time 为 1 秒，开启 Autostart。
2. 新建 `main.tscn`，按目标结构加入 Sprite2D 实例、Button 和 StatusLabel。
3. 在 Sprite2D 脚本中加入：

```gdscript
func _ready() -> void:
	$Timer.timeout.connect(_on_timer_timeout)

func _on_timer_timeout() -> void:
	visible = not visible

func _on_button_pressed() -> void:
	var is_running := not is_processing()
	set_process(is_running)
	motion_toggled.emit(is_running)
```

4. 在 Main 的 Signals 面板中不用操作；先选中 Button，把它的 `pressed` 连接到 Sprite2D 的 `_on_button_pressed()`。
5. 选中 Sprite2D 实例，把自定义 `motion_toggled` 连接到 Main。Main 的接收脚本如下：

```gdscript
extends Node2D

func _on_sprite_2d_motion_toggled(is_running: bool) -> void:
	$StatusLabel.text = "Running" if is_running else "Stopped"
```

6. 给 StatusLabel 设置初始文字 `Running`，保存并运行 Main。

### 阶段验收

- Timer 每秒切换一次图标可见性。
- 点击 Button 后，图标的运动/暂停状态切换。
- 每次切换时，StatusLabel 在 `Running` 与 `Stopped` 之间正确更新。
- 信号参数不是硬编码文字：Button 回调发出布尔值，Main 根据收到的值更新 Label。
- Debugger 没有节点路径或信号连接错误。

## 常见错误

- **`$Timer` 返回空节点。** Timer 必须是该 Sprite2D 的子节点，名称和大小写必须一致。
- **按钮没有反应。** 检查 `pressed` 是否连接到 Sprite2D，而不是只创建了同名函数。
- **状态文字不更新。** 检查自定义信号是否连接到 Main，以及回调参数名和 Label 节点路径。
- **运动暂停但闪烁仍继续。** 本练习只切换 Sprite2D 的 `_process()`，Timer 是独立子节点；这是预期行为。
- **图标跑出窗口。** 这是本练习的简化行为，边界限制会在完整 2D 游戏中加入。

## 拓展挑战（选做）

验收：方向键和 WASD 都能控制图标，脚本中不再直接读取物理键值。
