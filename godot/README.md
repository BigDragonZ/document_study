# Godot 4.7 官方文档中文学习笔记与渐进式练习

这套资料依据 [Godot Engine stable 官方文档](https://docs.godotengine.org/en/stable/)整理。stable 页面当前标示为 **Godot 4.7**，示例统一使用 **GDScript**。

它是中文学习导引，不是官方文档的逐段翻译，也不是已经完成的游戏工程。你需要在 Godot 编辑器中亲自完成练习。

## 适合谁

- 第一次使用 Godot，希望建立完整基础路径的学习者。
- 会一点编程，但不理解节点、场景和信号如何协作的学习者。
- 已看过零散教程，希望用一个小游戏串联知识的学习者。

完全没有编程基础时，先掌握变量、条件、循环和函数，再做练习 02；练习 01 不需要编程。

## 推荐学习方法

1. **先预测，再运行。** 修改属性或代码前，先写下你认为会发生什么。
2. **一次只改一个点。** 出问题时更容易定位原因。
3. **用验收标准代替“看懂了”。** 能独立重现运行结果，才算完成。
4. **保留自己的排错记录。** 记下错误信息、原因和修复方法。
5. **不要照抄完整答案。** 卡顿时先查对应笔记，再查官方页面和编辑器内置类参考。

## 环境与常用操作

准备一个 Godot 4.7 项目。前两个阶段使用新项目自带的 `icon.svg` 即可；完整 2D 游戏练习使用官方教程提供的素材，不需要第三方插件。

| 操作 | 通用快捷键 | macOS 官方教程标示 |
| --- | --- | --- |
| 运行项目（主场景） | F5 | Cmd + B |
| 运行当前场景 | F6 | Cmd + R |
| 停止运行 | F8 | Cmd + . |

如果“运行项目”和“运行当前场景”的结果不同，先检查是否设置了正确的主场景。
