快速找到命令、设置与问题答案

Reference（参考）是 ChatGPT 桌面应用的操作手册入口：查找命令和快捷键、了解斜杠命令、管理设置，并按症状排查问题。

阅读提示：本页按功能概念归纳官方内容。账户、平台、工作区设置与功能开放状态会影响实际界面；遇到差异时，以当前账户可用的设置和官方文档为准。
01

Commands：快捷操作与查找

Commands

命令与快捷键（Commands and keyboard shortcuts）帮助你在桌面应用中快速打开页面、切换视图和执行常见操作。快捷键会因 macOS、Windows、Linux 和当前功能是否可用而变化；可在设置中搜索动作，或按一个按键反查绑定动作。

两个容易混淆的搜索功能：Search chats（搜索聊天）用于重新找到过去的聊天；Find in chat（在聊天中查找）只搜索当前打开的聊天，不跨聊天。

macOS 常见示例：打开设置 ⌘ + ,；打开快捷键列表 ⌘ + /；打开命令菜单 ⌘ + ⇧ + P 或 ⌘ + K。请以你的快捷键设置为准。

来源：Commands

02

Slash commands：在输入框启动动作

Slash commands

斜杠命令（Slash command）是在聊天输入框键入 / 后从列表选择的动作。它不等同于键盘快捷键：快捷键通常是按键组合；斜杠命令是在当前输入框中触发的命令。

命令示例用途
/goal启动一个有明确完成标准的目标任务（在支持的环境中）。
/plan先梳理目标和步骤。
/archive归档当前聊天。
/compact压缩当前对话上下文。
/chat在适用环境中选择不属于项目的新聊天。

可用命令依环境、账户和权限而异；在输入框中键入 / 查看本机实际列表。技能也可用 $ 显式调用；这与斜杠命令的输入方式不同。

来源：Slash commands

03

Settings：管理偏好与权限

Settings

设置（Settings）管理应用的持续偏好和连接：个人资料、快捷键、通知、外观、个性化、记忆、归档聊天、浏览器与电脑操作权限等。某项设置可能在桌面、网页或工作区管理界面中。

用设置控制“默认如何工作”，用命令启动“现在执行某个动作”。权限/授权则决定可访问什么以及何时需要确认，不应把它们和一般显示偏好混为一谈。

来源：Settings

04

Troubleshooting：按现象排查

Troubleshooting

故障排查（Troubleshooting）先确认你在哪个应用、平台、账户和工作区，再按症状检查功能是否开放、权限是否允许、连接是否完成、目标环境是否正确。

1 · 确认范围记录所用应用、平台、聊天和任务。2 · 检查等待状态看任务是否在等批准、输入或权限。3 · 检查连接核对插件、浏览器扩展、应用权限和设备状态。4 · 缩小问题试一个更小、更明确的步骤；必要时重开应用或聊天。

若要提交诊断日志，先检查是否包含敏感信息。遇到命令行为异常时，确认当前文件夹、项目和分支；如果使用不同产品表面，确认参考资料对应的是 ChatGPT 桌面应用、ChatGPT 网页、Codex CLI 还是 IDE 扩展。

来源：Troubleshooting · Features
