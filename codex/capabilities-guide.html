CHATGPT LEARN · 用对工具，让 ChatGPT 看、找、做、生成

用对工具，让 ChatGPT 看、找、做、生成

Capabilities（能力）是 ChatGPT 用来理解信息、访问工具、执行操作和生成内容的能力集合。先看任务需要什么，再选择合适的能力。

阅读提示：本页按功能概念归纳官方内容。账户、平台、工作区设置与功能开放状态会影响实际界面；遇到差异时，以当前账户可用的设置和官方文档为准。
01

先按任务选能力

Choose by the job

不要把所有能力都当成同一种“工具”。有的负责取信息，有的操作界面，有的理解输入，有的生成新内容。

需求能力核心区别
查最新公开信息Web search（网页搜索）搜索公开网页并呈现来源；搜索结果仍需核对。
浏览现有标签页或网站Browser（内置浏览器）/ Browser extension（浏览器扩展）内置浏览器提供独立浏览环境；扩展连接你已有的浏览器与登录状态。
点击、输入、操作桌面界面Computer Use（电脑操作）通过屏幕和控件操作获准的桌面应用。
检查图片 / 创作图片Image inputs（图像输入）/ Image generation（图像生成）一个理解现有图像，一个创建或编辑图像。
反复按规则做任务Plugins（插件）组合可复用的技能与服务连接。
02

网页与电脑操作

Browser · Computer Use · Browser extension

内置浏览器（Browser）适合在 ChatGPT 提供的浏览环境里打开网页和继续网页任务。浏览器扩展（Browser extension）让桌面应用连接到你现有的 Chrome、Edge、Brave、Opera 或 Vivaldi 浏览器，可利用当前配置文件和已打开页面。

电脑操作（Computer Use）能查看屏幕并操作获准的应用窗口，适合需要视觉判断、点击流程、桌面设置或跨应用操作的任务。它与结构化插件不同：插件适合稳定的服务数据与操作；电脑操作适合图形界面。操作前应检查应用权限提示，限定目标窗口与步骤。

简记：公开网页找资料 → Web search；使用已有浏览器页面 → 浏览器扩展；需要看屏幕并点按软件 → Computer Use。

来源：Browser · Computer Use · Browser extension

03

语音沟通与文字输入

ChatGPT Voice

ChatGPT Voice（ChatGPT 语音）用于和 ChatGPT 实时对话，可边说边沟通、追问、调整方向。语音听写（voice dictation）则把说出的话转成输入框里的文字，供你检查、编辑后再发送；它不是持续的语音对话。

语音可用性和控制方式随设备、账户和界面变化。语音会话结束，并不一定会停止已经委托的后台工作；要停止任务，需另外管理任务本身。

来源：ChatGPT Voice · Prompting / voice dictation

04

输入辅助与插件

Composer Predictions · Plugins · Sign in with ChatGPT

输入框预测（Composer Predictions）根据当前 Codex 对话建议下一条消息。按 Tab 会把建议放入输入框作为草稿，你可以编辑；它不会自动发送，也不会自行查找记忆或连接应用中的资料。

插件（Plugin）把可复用的技能或外部服务能力带入聊天。使用 ChatGPT 登录（Sign in with ChatGPT）是用 ChatGPT 账号登录合作应用；登录和授权应用读取数据、执行操作是分开的，应用若要使用 ChatGPT 方案额度也需单独授权。

对比：插件连接能力；Sign in with ChatGPT 处理身份登录；输入框预测只建议文字，不替你确认或提交。

来源：Composer Predictions · Plugins · Sign in with ChatGPT

05

搜索与信息核验

Web search

网页搜索（Web search）是 ChatGPT 的联网搜索能力，适合需要当前信息的问题。聊天记录会保留搜索活动和相关工具调用。官方提醒：网页结果属于外部输入，引用网页时应检查来源、时间与内容是否支持结论。

它不同于浏览器操作：搜索重点是从网页发现和整理信息；浏览器则用于访问和操作页面或当前标签。若问题依赖最新规则、价格、版本或事件，应使用实时搜索并查看引用来源。

来源：Web search

06

图像理解与创作

Image inputs · Image generation · Appshots

图像输入（Image inputs）把截图、图表、设计稿或照片作为提示上下文，让 ChatGPT 检查现有图像。告诉它图中是什么、重点看哪里、希望得到什么结果。

图像生成（Image generation）用于创建或编辑图像；参考图可帮助保留元素或指定视觉方向。应用截图（Appshot）是从桌面当前前台应用捕获画面及可读取文字并送入聊天，适合快速分享屏幕现场；部分应用只会提供可见画面，而非整份文档内容。

对比：看图 → Image inputs；生成或修改图 → Image generation；快速把当前桌面窗口发给聊天 → Appshots。

来源：Image inputs · Image generation · Appshots

07

文件工作

Work with files

文件工作（Work with files）涵盖阅读来源文件、生成文档/演示文稿/电子表格/PDF、预览和修订。有效请求应说明来源资料、目标文件类型、结构和审阅标准。生成后使用预览检查内容、数据、版式与计算结果，并针对具体问题给反馈。

文件预览和标注能力因平台而异；生成 HTML 时部分环境可提供交互预览。Codex CLI 可创建与编辑文件，但不包含同样的可视预览界面。

来源：Work with files
