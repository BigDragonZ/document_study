在 Space 里共同编辑和分享工作

ChatGPT Space（ChatGPT 协作空间）集中管理页面、幻灯片、文件与共享内容，让你、ChatGPT 和协作者在同一组资料上继续工作。

阅读提示：本页按功能概念归纳官方内容。账户、平台、工作区设置与功能开放状态会影响实际界面；遇到差异时，以当前账户可用的设置和官方文档为准。
01

Workspace、Space 与 Page

Core concepts

Workspace（工作区）是你登录的个人或组织环境，决定成员身份、设置和可用应用；Space（空间）是在该工作区中组织相关页面与协作内容的地方；Page（页面）则是你和 ChatGPT 可以共同编辑的文档。

Space 可围绕一个主题或团队分组；也可以单独创建页面。与 Project 相比，Project 的重点是相关聊天、文件和任务上下文；Space 的重点是可编辑页面、幻灯片、文件和多人协作。

来源：ChatGPT Space overview

02

页面、子页面与幻灯片

Pages and slides

页面可包含标题、段落、表格、图片、文件、代码块、重点标记、链接和子页面。用 / 打开插入菜单；用子页面把细节拆开，保持主页面简洁；链接现有页面则可引用而不移动内容。

ChatGPT Slides（ChatGPT 幻灯片）让你从对话、文件或模板生成团队可编辑的演示文稿，并可与团队和 ChatGPT 一起修改、演示或导出。Space 也可汇集电子表格、Sites、图片和上传文件。

来源：Work with pages · Get started with Space

03

与 ChatGPT 或 dot 一起写

Work with agents

可在页面旁边的对话讨论更大的问题或修改；选中一段文字后请求改写；也可在页面内输入 @ChatGPT 或 @dot 让它们起草、研究或修订。用 / 菜单可生成文字、添加可视化或图像。

明确是要它在聊天里回答，还是直接修改页面；检查建议修改后再接受。多人协作时，说明要改的具体段落，并保留已经确定的结论。

来源：Work with agents in Space

04

权限与协作

Collaboration
权限协作者能做什么
View（查看）阅读内容。
Comment（评论）阅读并留下反馈。
Edit（编辑）与你共同修改内容。

可单独分享页面，或在功能可用时分享整个 Space，让受邀者访问相关页面。子页面可能继承父页面或 Space 的访问权限。分享页面不会分享你的私人聊天或保存的记忆。

来源权限：链接文件保留原始权限；复制或摘要到页面里的内容对能访问页面的人可见。分享前要同时检查页面内容、链接来源和访问对象。

来源：Collaborate in Space · Manage ChatGPT Space

05

Space 与 Project

Space vs Project
功能核心单位适合工作
Project（项目）聊天、项目文件、共享上下文长期、多聊天、多阶段任务。
Space（空间）页面、幻灯片、文件、协作权限共同撰写、组织和分享可编辑成果。
Page（页面）Space 中的一份协作文档记录计划、研究、手册或会议结果。
Chat（聊天）一段对话讨论、请求草稿或让代理执行工作。
