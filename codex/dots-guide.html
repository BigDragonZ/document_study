让 dot 持续跟进重要工作

ChatGPT dots（dot 助手）是可持续承担职责、记住工作偏好并在后台跟进任务的个性化助手。它区别于每次从零开始的普通聊天，也不同于只处理单项交付的 ChatGPT Work。

阅读提示：本页按功能概念归纳官方内容。账户、平台、工作区设置与功能开放状态会影响实际界面；遇到差异时，以当前账户可用的设置和官方文档为准。
01

dot 的工作方式

Overview

dot（你的 dot 助手）是可命名和个性化的持续协作助手。你可以给它不止一项长期责任，例如追踪筹备事项、整理决定和未解问题、在重要时刻提醒你，并为你草拟待审阅的消息。

dot 会结合当前对话、相关 ChatGPT Memory（记忆）和自己的已保存笔记来理解偏好与持续工作；它不等于每次任务都自动带入完整的历史聊天记录。dot 的长期笔记也与 ChatGPT Memory 有区别。

来源：Meet dots · Tasks and memory

02

创建与连接

Getting started

可在 ChatGPT 手机或桌面应用、桌面浏览器中创建 dot，设置名称与外观，再连接它要用的应用插件、消息渠道或电脑。连接可以之后再补充。

消息渠道

决定你能从哪里联系 dot，例如 ChatGPT 或获准的外部消息渠道。

应用连接

提供读取资料或使用工具的能力。需单独完成授权。

电脑连接

让 dot 在需要时访问本地文件、已登录浏览器上下文或本地 Codex 任务。

云端环境

dot 有自己的云端电脑和浏览器；不用本地电脑时也可处理支持的工作。

重要区别：连接消息渠道不会自动开放邮箱、其他 App 或电脑权限；连接电脑也不能替代 App 授权。需要本地电脑时，应保持电脑联网、ChatGPT 桌面应用开启并登录。

来源：Get started with your dot · Connect computers and apps

03

委托持续工作

Tasks and memory

给 dot 描述持续责任、相关来源、哪些决定要你确认、什么情况下打扰你。dot 可以持续跟进、按计划或支持事件运行，并委托部分工作给 ChatGPT Work 或 Codex；你可以补充上下文、调整优先级或作出决定，不必每次重新开一个请求。

“主动研究”（proactive research）是 dot 对有权限读取的信息做背景研究并保存私人笔记；它本身不会发送消息、修改连接应用或控制浏览器/电脑。需要执行动作时，仍须有对应工具权限，并遵循确认机制。

来源：Tasks and memory · Message your dot

04

查看进度与控制

Controls

在桌面应用中打开 dot 的个人资料与 Activity（活动）查看任务进度、文件、结果，以及等待你决定的事项。dot 在涉及账户或分享信息的操作前会进行自动审查；可能直接继续、请求批准，或要求你亲自完成一步。

控制动作含义
Pause dot（暂停 dot）暂时停止 dot 承担的持续职责。
Stop task（停止任务）停止单项已委托工作。
Cancel schedule（取消计划）取消未来按时或事件触发的运行。

这三种操作效果不同。草拟回复也不等于获准发送；对外操作、账户连接和设备权限仍有独立审核。

来源：Control your dot

05

dot、Work 与 Codex

How they differ
工具适合什么核心模式
普通聊天问答、讨论、一次性请求围绕当前对话进行。
ChatGPT Work明确的研究、分析、文件等交付任务委托一项任务并审阅结果。
Codex编码、仓库与技术任务在代码项目或开发环境完成任务。
dot有持续责任、需要记住偏好和适时跟进的工作长期协作，可委派具体工作。
